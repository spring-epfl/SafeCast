# MLS-SRTP

This repository implements and evaluates MLS-SRTP.

MLS (Messaging Layer Security) provides group key management, and SRTP secures
real-time media transport. Together, MLS-SRTP enables end-to-end group media
protection with efficient rekeying as participants join, leave, or are removed.
By relying on MLS, the design also inherits forward secrecy and post-compromise
security.
